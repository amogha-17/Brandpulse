A Python analytics tool for social media marketers
A Python analytics tool for social media marketers.
## What it does
Upload your Instagram post data or PPC campaign CSV and get instant insights:
- Average engagement rates
- Best posting times
- ROAS calculations
- Interactive charts

- Streamlit
- Plotly
